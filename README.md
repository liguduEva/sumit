
# Sweet Crumbs Pops Bakery - Website Repository

## Project Overview
An interactive and SEO-optimized web application for **Sweet Crumbs Pops Bakery**, based in Pretoria, South Africa.

---

## Part 3 Development Changelog & Feedback Implementation

### 1. Feedback Corrections from Part 2
* **Navigation & Mobile Responsiveness**: Improved mobile hamburger menu toggling and added responsive CSS flexbox layout for screen widths below 768px.
* **Form Layout**: Refactored input labels and error containers across `enquiry.html` and `contact.html` for accessibility compliance.

### 2. Part 3 Feature Additions
* **Interactive Accordion & Tabs**: Implemented Vanilla JS accordion controls for FAQs and tab panel switching for product categories.
* **Interactive Map Integration**: Integrated Leaflet.js with OpenStreetMap tiles pointing to Pretoria HQ coordinates `[-25.7479, 28.2293]`.
* **Gallery Lightbox**: Built a dynamic modal image lightbox to preview bakery product images in high resolution.
* **Dynamic Menu Filter**: Created live client-side string filtering and dropdown category matching.
* **Form Validation Engines**:
  * `enquiry.html`: Added real-time client-side checks (name length, SA phone format, future date picker verification) and live dynamic price calculation.
  * `contact.html`: Added string length rules, email regex validation, and automated `mailto:` link compiler.
* **SEO & Deployment**:
  * Added targeted title tags, meta keywords, and meta descriptions across all HTML files.
  * Created root-level `robots.txt` and `sitemap.xml`.
  * Deployed site on Netlify / GitHub Pages.
